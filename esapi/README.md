# ESAPI & ARIA toolbox

Personal public collection by Maximilian Grohmann: own repositories, selected starred projects and sources from previous ESAPI talks. Static HTML, CSS and JavaScript; no analytics, forms, external fonts or runtime dependencies.

Live page: https://kiragroh.github.io/esapi/

`repos.json` contains the shareable collection. The cards in `index.html` are also rendered statically so all links remain usable without JavaScript. Keep both in sync when adding entries. `app.js` provides search and workflow filters.

The hero is an AI-generated conceptual illustration, not an application screenshot or a patient example. It was generated with the built-in image-generation tool using a prompt for a white-background blue/purple illustration connecting code, software modules and a stylized radiotherapy workflow. No third-party application code is redistributed. Linked projects retain their original licenses.
